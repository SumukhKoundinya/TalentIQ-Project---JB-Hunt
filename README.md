# TalentIQ Synthetic Prototype

This workspace contains a static, synthetic-data TalentIQ candidate capture and review dashboard inspired by the J.B. Hunt business and TalentIQ capstone proposal.

## Files

- `index.html` — page layout and dashboard structure.
- `styles.css` — full visual styling and responsive UI design.
- `app.js` — synthetic candidate dataset, filtering, candidate selection, and chart rendering.

## Local usage

From the workspace root:

```bash
python -m http.server 8000
```

Then open:

http://127.0.0.1:8000/
