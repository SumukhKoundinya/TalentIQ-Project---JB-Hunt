# TalentIQ Enterprise Redesign Plan

> **Goal:** Transform TalentIQ from a basic candidate review dashboard into a full enterprise-grade career fair capture and triage tool with J.B. Hunt corporate branding, SPA view switching, and 6 working views.

**Architecture:** Single-page app with JS-based view router. All views in one `index.html` container, toggled via `data-view` attributes. No build system — vanilla JS + CSS. JS split into 5 files loaded via `<script>` tags (no ES modules — avoids CORS issues with `python -m http.server`).

**Tech Stack:** Vanilla HTML/CSS/JS, MediaRecorder API (audio), IndexedDB (audio blob storage), localStorage (state persistence), CSS custom properties (design system), QR code generation (lightweight canvas-based)

**Brand:** J.B. Hunt corporate — Yellow `#FEDB00`, Blue `#005DBA`, Digital Black `#211F20`, Icicle Blue `#E2E8F0`. Enterprise feel with dark sidebar.

**Sponsor:** Carl Pegue, J.B. Hunt (carl.pegue@jbhunt.com)

**Users:** University Recruiters, Hiring Managers, Recruiting Coordinators

### B. Audit Log Schema

```javascript
// Each entry in candidate.auditLog[]
{
  action: "CREATED" | "APPROVED" | "EDITED" | "FOLLOW_UP" | "INTERVIEW_REQUESTED" | "STATUS_CHANGED" | "AUDIO_ADDED" | "NOTES_UPDATED" | "SUMMARY_GENERATED" | "SUMMARY_EDITED",
  recruiter_id: "R1",                    // which recruiter performed action
  timestamp: "2026-09-14T14:23:05Z",    // ISO 8601
  time_to_complete: 45,                  // seconds from record open to action (for research)
  detail: "Status changed to Interview Requested"
}
```

### C. Missing Data Indicator Schema

```javascript
// Each entry in candidate.missingData[]
{

  label: "Work Authorization",           // human-readable label

  reason: "Required for eligibility verification"
}

## Global Constraints

- WCAG 2.2 Level AA compliance: visible focus indicators, 4.5:1 contrast ratio, keyboard navigable, aria-labels on all interactive elements

TIQ.ai = {

  // Template engine reads candidate fields + notes
  // Builds prose summary from available data
  // Generates traceability[] citing which fields were used
  // Generates missingData[] for unfilled fields
  // Returns { summary: string, traceability: string[], missingData: object[] }
}
```

**Summary template rules:**
- Start with education: `"{firstName} {lastName} is a {major} {degreeProgram} student at {university}"`
- Add GPA if present: `"with a {gpa} GPA"`
- Add skills: `"Skills include {skills.join(', ')}"`
- Add notes summary: first 2 sentences of recruiter notes
- Add work authorization if present: `"Work authorization: {workAuthorization}"`
- Add locations if present: `"Preferred locations: {workLocations.join(', ')}"`

**Traceability generation:**
- For each data field used in summary, generate a citation: `"{field value} — from {source}"`

**Missing-data indicator generation:**
- Check each core field: workAuth, graduationDate, gpa, phone, resume, locations
- If empty, add to missingData[] with severity:
  - critical: workAuth, graduationDate
  - important: gpa, resume
  - nice-to-have: phone, locations
